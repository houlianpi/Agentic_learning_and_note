# Agentic AI 学习

> 类型：主题阅读
> 状态：在读
> 目标：理解 AI Agent 的能力边界，并沉淀成可复用的学习和实践框架。

## 一句话总结

Agentic AI 的关键不是让模型“更聪明”，而是把目标、上下文、工具、反馈和验证组织成一个可持续执行的系统。

## 阅读问题

- Agent 和普通聊天机器人的本质区别是什么？
- 什么任务适合交给 Agent，什么任务应该保留人工决策？
- 如何评价一个 Agent 工作流是否可靠？
- 如何把读到的概念转成自己的项目实践？

## 当前结论

1. Agent 的价值来自持续推进任务，而不是单次回答。
2. 工具调用必须配合可验证的中间结果，否则自动化会放大错误。
3. 好的 Agent 体验需要清楚显示计划、进度、证据和可回退点。
