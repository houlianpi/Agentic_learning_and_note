# 笔记系统

目标是把读书笔记从“摘抄仓库”变成“可复用的思考系统”。

## 三层结构

| 层级 | 目的 | 文件位置 |
| --- | --- | --- |
| 书架 | 管理所有书和主题 | `docs/books/index.md` |
| 单本书 | 记录核心观点和章节入口 | `docs/books/<book>/index.md` |
| 章节 | 保存细节、例子和行动 | `docs/books/<book>/<chapter>.md` |

## 笔记原则

1. 先写问题，再写摘抄。
2. 每章至少提炼一个自己的判断。
3. 把“觉得有用”改写成一个可执行动作。
4. 定期复盘旧笔记，而不是只追加新笔记。

## 推荐格式

每篇笔记尽量包含：

- 本章问题
- 核心观点
- 我的理解
- 可执行行动
- 保留怀疑
